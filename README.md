# Premium Motors Rental System

A console-based car rental management system developed using C++. This project provides customer rental services and an administrative dashboard with vehicle management, rental calculations, financial reports, and maintenance tracking.

## Imp
Currently the admin and the password are open-source
## Features

### Customer Portal
- Browse vehicles by category
- Check vehicle availability
- Rent vehicles
- Calculate rental costs
- Add optional insurance and driver services
- Return rented vehicles
- Early return and vehicle upgrade options
- Trip planner with estimated travel costs

### Admin Dashboard
- View rented vehicles
- Manage customer records
- Generate financial reports
- Track vehicle maintenance
- View rental history
- Monitor overdue rentals
- Edit vehicle details
- Configure rental rates
- Reset application data

## Vehicle Categories

- Hatchback
- Sedan
- SUV
- Luxury
- Van

## Technologies Used

- C++
- Object-Oriented Programming concepts
- Functions and Arrays
- File Handling
- Conditional Statements and Loops
- Date and Time Functions

## How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE.
3. Compile `premium_rentals.cpp` using a compatible C++ compiler.
4. Run the generated executable.

### Using GCC

```bash
g++ premium_rentals.cpp -o premium_rentals
```

On Windows, run:

```bash
premium_rentals.exe
```

## Data Storage

The application uses text files for local data persistence. These files are generated when the application runs.
